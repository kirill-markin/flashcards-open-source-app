# Approved Nibomo Google Play cards

Download these finished cards and review previews using the
[media archive procedure](../../../../../docs/media-assets.md). Open `index.html` to select a language and inspect the full-size cards.

The [processing guide](../../../../../docs/store-screenshot-processing.md#approved-delivery)
owns the inventory, store-upload status and links to the manual refresh
procedure.

[Localization provenance](localization-provenance.json) gives the exact ordered
phone cards and feature graphic for each of the nine November 2026 main and
custom draft locales. Resolve each locale through `listingAssets` and follow
`phoneSets` in order. Hong Kong shares Taiwan’s first phone card and keeps its
own remaining four cards and feature graphic. English (Canada and U.K.) shares
Australia’s set and feature graphic, and Malay (Malaysia) shares the Malay set
and feature graphic. These placements were verified in reopened drafts.

`export-manifest.json` and `source-manifest.json` are retained from the approved
delivery and record its original source/export provenance; their revision and
hashes describe that original package.
Reusable design assets, copy and locale maps are in the
[processor assets](../../../../../scripts/store-screenshots/assets/).

Feature-graphic links use the existing `../play-store-feature-graphic/` files.
The package summary counts those linked banners; none are duplicated here.
