# App Store Custom Product Pages

Keep one Markdown file per page. Record shared page settings once and use one
section per App Store locale for exact promotional text and keyword assignments.
Shared listing text and the full keyword lists live in
[App Store Connect Metadata](../app-store-connect-metadata.md).

## Pages

- [Open source search](open-source-search.md)

## App Store Connect

1. Open **Nibomo → Distribution → Custom Product Pages**. Create the page with
   the reference name and starting point in its file.
2. Copy the promotional text into the matching localization. Apply the page
   settings and verify the saved text, locale and asset order. When reusing
   default assets, select the matching assets for each added localization.
3. Submit the page to App Review. Once the page is approved and visible, select
   its search keywords from the latest approved app version for each locale
   and click **Publish** in the Keywords section. Verify the page at its
   generated URL and in the intended searches.
   [Apple setup and keyword publishing](https://developer.apple.com/help/app-store-connect/create-custom-product-pages/configure-multiple-product-page-versions/)
