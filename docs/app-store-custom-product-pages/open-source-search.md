# Open source search

Use this source for the Nibomo custom page on iPhone and iPad. Each locale has
promotional text and a keyword candidate. Check local search demand and ranking
before assigning a candidate. Assign it only once it appears in the latest
approved default app metadata for the matching locale. Add a missing term in a
regular iOS update if it passes the check. [Default listing metadata](../app-store-connect-metadata.md)

## Page settings

| App Store Connect field | Value |
| --- | --- |
| Reference Name | `Open source search` |
| Starting point | Copy the approved default product page. |
| Screenshots | Reuse the default iPhone and iPad screenshots for each locale in their existing order. |
| App Previews | Reuse the corresponding default locale’s setup. |
| Search Results artwork | Reuse the corresponding default locale’s setup. |
| Product Page Header | Reuse the corresponding default locale’s setup. |
| App Deep Link | Leave empty. |
| Product Page URL | Apple generates the URL. Use it for internal checks during MKT-005. |
