# Google Play custom listings

| Listing | Audience |
| --- | --- |
| [Open source search](open-source-search/README.md) | People looking for open-source flashcards |

Keep one Markdown file per listing. Record its internal Play Console name, default language, targeting and selected keyword variants, and the complete text for each overridden field. If a listing grows to many translations, put its shared settings in its own `README.md` and give each locale a file named with the exact Play locale code.

Copy the text blocks into Play Console. Use the linked [main listing metadata](../google-play-store-metadata.md) and [pinned media](../media-assets.md) for shared copy and assets. Play category and tags are app-wide settings. Search keywords belong to the individual custom listing. [Custom listing setup](https://support.google.com/googleplay/android-developer/answer/9867158?hl=en) · [Play category and tags](https://support.google.com/googleplay/android-developer/answer/9859673?hl=en)
