# Open source search

| Play Console field | Value |
| --- | --- |
| Internal listing name | `Open source search` |
| Default language | [English (United States), `en-US`](en-US.md) |
| Targeting type | Search keywords |
| Search terms to verify | `open source`, `open-source flashcards`, `open source flashcard app` |

Check the keyword picker for these terms and their localized variants. Select variants that match open-source flashcard intent and record the exact selections here once verified. Use the language files below for the copy shown on this listing. [Google keyword targeting and translations](https://support.google.com/googleplay/android-developer/answer/9867158?hl=en)
