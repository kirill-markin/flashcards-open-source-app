# Publishing to the MCP Registry

The companion owns the [manifest](https://github.com/kirill-markin/nibomo-plugins/blob/main/server.json).
Core owns the validator, credential-reading publisher workflows/scripts and
operator instructions; follow [plugin publishing](plugin-publishing.md#mcp-registry)
for validation, credential setup, selected-release publication and troubleshooting.
The [MCP release gate](release/mcp-and-plugins.md#mcp) owns release verification.
