# Nibomo

AI-powered, open-source flashcards for iPhone, iPad, Mac, Android, and the web.

![Nibomo screenshots](https://github.com/kirill-markin/flashcards-open-source-app/releases/download/media-archive-20261017/readme-screenshots.png)

Prepare for exams, learn vocabulary, and memorize technical terms and facts. Create and improve cards with AI, study offline on mobile, and review with FSRS spaced repetition.

## Available on

- [iPhone and iPad](https://apps.apple.com/us/app/flashcards-open-source-app/id6760538964) — including iPhone Duo; iOS / iPadOS 18+.
- [macOS](https://apps.apple.com/us/app/flashcards-open-source-app/id6760538964) — macOS 15+ on Apple silicon via Mac Catalyst.
- [Android](https://play.google.com/store/apps/details?id=com.flashcardsopensourceapp.app&pcampaignid=web_share) — Android 11, 12, 12L, 13, 14, 15, 16, and 17.
- [Web](https://app.nibomo.com/review) — study in your browser.
- [AI assistants via MCP](https://nibomo.com/docs/mcp-connector/) — connect at `https://mcp.nibomo.com/mcp`.
