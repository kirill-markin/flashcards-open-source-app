# Contributing

Contributions are very welcome!

## Making changes

- Follow the repository's existing data model and logic.
- Improve the app incrementally rather than fully rewriting it.
- Keep each pull request focused on related changes. Submit independent changes in separate pull requests.

## Lifetime premium

After your pull request is merged, you may ask maintainer [Kirill Markin](https://kirill-markin.com/) for lifetime premium for [nibomo.com](https://nibomo.com/), giving you full access to all app features.
